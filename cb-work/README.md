# Command Book — 命令速查

> 中文描述搜命令：Linux / Redis / Git 命令速查与配方，支持收藏、最近查看。

本项目是对开源站点 [command-book-web](https://11052022.github.io/command-book-web/) 的本地化整理，将其完整内容抓取后生成了一份 Markdown 文档和一个样式高度还原的自包含网页。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `command-book.html` | 自包含网页，样式与交互按原站还原，双击即可在浏览器打开 |
| `command-book.md` | 全部命令与配方的 Markdown 文本版，便于阅读、检索、迁移 |
| `README.md` | 本说明文档 |

## 内容概览

共 **298 条命令** 与 **61 个配方**，按模块分布如下：

| 模块 | 图标 | 命令数 | 配方数 |
| --- | --- | --- | --- |
| Linux | 🐧 | 155 | 20 |
| Redis | 🔴 | 103 | 18 |
| Git | 🔀 | 40 | 23 |

Linux 命令按分类组织（磁盘存储、文件操作、网络相关、包管理、进程管理、系统信息、文本处理、用户权限等）；Redis / Git 命令按其层级分类（如 string、hash、list、branch、remote 等）。

每条命令包含：等级（低危 / 中危 / 高危 / 极高危）、描述、语法、常用参数、示例、相关命令、标签。
每个配方包含：描述、一键执行命令、步骤拆解、标签。

## 功能特性（HTML）

- **暗 / 亮主题**：默认暗色，顶栏「亮色 / 暗色」按钮一键切换（记忆偏好）
- **模块切换**：Linux / Redis / Git 三个模块顶部切换
- **分类导航**：左侧「命令分类」侧栏，按分类过滤并显示数量
- **搜索**：中文描述多关键词搜索（空格分隔），支持 `#recipe` / `#命令` 快捷切换，带联想下拉
- **筛选**：全部 / 命令 / 配方三档过滤
- **卡片展开**：点击卡片展开「常用参数 / 示例 / 相关命令」；配方展开「步骤拆解」
- **代码复制**：示例、一键执行、步骤代码块一键复制
- **收藏 / 最近查看**：星标收藏、自动记录最近查看，支持一键清空
- **紧凑模式**：顶栏「紧凑」按钮切换更紧凑的列表显示

## 使用方法

- 网页版：直接用浏览器打开 `command-book.html`。
- 文本版：用任意 Markdown 编辑器 / 阅读器打开 `command-book.md`。
